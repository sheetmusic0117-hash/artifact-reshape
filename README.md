# 聖遺物重塑模擬器

原神「啟聖之塵」重塑的最佳保底選法計算工具。純前端靜態網頁，可直接放在 GitHub Pages。

## 功能

1. **聖遺物設定**：四個詞條的類型、目前數值、初始詞條數（3 或 4）、保底次數（2/3/4）。
   填入目前數值後會自動推算每個詞條命中幾次、初始值可能是哪一檔；也可手動指定初始檔位。
2. **收益比例**：每個詞條一個比例。收益 = Σ 比例 × 數值 ÷ 該詞條平均單次值。
3. **保留條件**：以模塊組合，可用「且 / 或」連接（且優先於或）：
   - 強化命中：勾選的詞條命中合計 ≥ N 次
   - 收益總和 ≥ S（可一鍵填入目前收益）
   - 單一詞條數值 ≥ V
4. **結果**：六種保底選法的成功率、平均嘗試次數、成功時平均收益、保底觸發率。
   圖表預設顯示成功時平均收益，可切換成成功率；表格與圖表都依「成功率 × 成功時平均收益」由高到低排序。
   點選任一選法可看到：
   - 命中組合散佈圖（橫軸為該組合平均收益，縱軸為機率）
   - 收益分數的精確分佈直方圖
   - 達標組合列表，點選可在兩張圖中單獨標示
5. **多選比較**：勾選比較表的「比較」欄（或按住 Ctrl／⌘ 點圖表柱），最多同時比較 3 種選法。
   組合細節會把它們疊在同一張散佈圖與分數分佈圖上，各用一種顏色與點的形狀，組合表多一欄「選法」；
   匯出組合表時會包含所有選中的選法。直接點表格列則回到只看單一選法。
   上限是 3 組，因為散佈圖上超過 3 種顏色就無法保證色盲也分得出來。

設定會存在網址 `#` 後面，可直接複製網址分享同一組設定。

### 匯出 / 匯入

- **匯出設定與結果（JSON）**：包含完整設定、初始收益、每種選法的結果與所有命中組合。
- **匯入 JSON**：讀回設定並重新計算（只含 `settings` 或只有設定本身的檔案也可以）。
- **匯出比較表 / 組合表（CSV）**：可直接用 Excel 開啟（UTF-8 BOM）。組合表匯出目前選中的選法。

### 語言

右上角可切換 **简体中文**（預設）、**繁體中文**、**English**，選擇會記在瀏覽器裡。

介面文字都在 `i18n.js`。要改文字時，改 `tools/gen_i18n.py` 裡的繁中（`HANT`）與英文（`EN`），
再執行 `python tools/gen_i18n.py i18n.js`：簡中會由繁中經 OpenCC（`pip install opencc`）
自動轉換，並把「爆擊」換成陸服用語「暴击」。

## 計算方式

不是隨機模擬，而是**精確窮舉**：

- 每次強化等機率落在四詞條之一；每次數值等機率為第七～第十檔。
- 保底在結果確定後調整：若選中兩詞條的強化命中合計 < 保底，逐次從未選中詞條隨機搬一次命中
  （依命中次數加權）到兩個選中詞條之一（各 1/2），直到合計 = 保底。
- 枚舉所有命中組合 × 所有檔位組合，所以分數分佈是精確的離散分佈。

> 保底實際怎麼把命中搬到哪個詞條，遊戲沒有公開。上面是本工具的假設，
> 要換規則只需修改 `engine.js` 的 `hitDist()`。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面 |
| `style.css` | 樣式（自動深色模式） |
| `engine.js` | 計算核心（瀏覽器與 Node 共用） |
| `app.js` | 介面與圖表（Chart.js 4.4.1，CDN） |

## 本機預覽

```
python -m http.server 8765
```

然後開啟 http://localhost:8765 。

## 部署到 GitHub Pages

1. 在 GitHub 建立新 repository，把這個資料夾的檔案推上去。
2. Repository → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`。
3. 幾分鐘後網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。
